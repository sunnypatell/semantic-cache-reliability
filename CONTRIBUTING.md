# Contributing

This repository is an archival research artifact, released for independent reproduction
and verification of the paper *When Semantic Caches Lie*. It is not an open-source project
seeking collaborators.

- **Pull requests and feature contributions are not accepted.** The work is the author's
  intellectual property and is licensed source-available for reproduction only (see
  [`LICENSE`](LICENSE)); accepting external code would create ambiguous ownership over a
  cleanly-owned artifact.
- **Reproduction problems and factual errors are welcome.** If a result does not reproduce,
  a figure or number looks wrong, or a citation is incorrect, please open an issue or
  contact the author at the address in [`CITATION.cff`](CITATION.cff). Please include the
  exact command, environment, and observed vs. expected output.

Thank you for reading the work carefully.
