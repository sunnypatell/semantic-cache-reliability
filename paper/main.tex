\section{Introduction}
\label{sec:intro}
Semantic caching reuses a stored answer when a new query is judged close enough
to an earlier one. The judgment is an embedding similarity test: if
\(\cos(\mathbf{e}_q, \mathbf{e}_c) \ge \tau\), the cache returns the stored
response. \Cref{tab:smoke} previews the comparison structure. The risk we study
is the \emph{false hit}: a query served a stored answer that does not actually
answer it. Prior work on verified caching reduces this error online~\cite{vcache2025},
building on sentence embeddings~\cite{sentencebert2019} and retrieval-augmented
generation~\cite{rag2020}.
